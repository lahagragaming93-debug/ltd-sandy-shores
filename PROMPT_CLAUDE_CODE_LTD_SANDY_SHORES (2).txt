## CONTEXTE DU PROJET

Tu dois créer une plateforme web complète de gestion pour le LTD Sandy Shores,
une épicerie multisites avec franchise de stations-essence opérant sur un serveur
FiveM (jeu de rôle GTA). Toutes les données financières sont en dollars RP ($).

La plateforme doit :
- Recevoir et parser automatiquement des données via un bot Discord (qui lit les
  canaux de logs et relaie vers Firebase)
- Gérer les stocks, les ventes, la comptabilité et les ressources humaines
- Être accessible par rôles (patron, co-patron, DRH, responsables, employés)
- S'afficher en FRANÇAIS uniquement
- Clôturer la semaine automatiquement chaque dimanche à 00h00

---

## STACK TECHNIQUE

- Frontend : HTML / CSS / JavaScript (vanilla ou React)
- Base de données : Firebase Firestore
- Authentification : Firebase Authentication
- Réception des données : Bot Discord (lit les canaux de logs → envoie à Firebase)
- Hébergement : GitHub Pages (frontend statique) + Firebase (Firestore + Auth + Functions)
- Style visuel : Far-West / Western — couleurs rouge sang (#8B0000),
  beige sable (#D2B48C), noir (#1a1a1a), blanc cassé (#F5F0E8)
  Typographie robuste, style panneau de saloon, ambiance Sandy Shores

---

## ARCHITECTURE GÉNÉRALE

Modules principaux :
1. Dashboard Patron / Direction (vue globale)
2. Gestion des Stocks (épicerie + essence)
3. Gestion des Ventes (corrélation factures + logs inventaire)

## GESTION DES COMPTES ET ACCÈS

Flux de création des comptes :

1. Le Patron ET le Co-Patron créent EUX-MÊMES leur propre compte directement
   sur la page d inscription du site (première utilisation).
   Ces deux comptes ont automatiquement tous les droits (accès total).

2. Une fois connectés, le Patron ou le Co-Patron créent les comptes des autres
   membres depuis le panneau Administration :
   - Ils saisissent : prénom NOM RP, ID Discord, ID Perso, et choisissent le rôle.
   - Le système génère un login + mot de passe provisoire à transmettre à l employé.
   - L employé peut changer son mot de passe à sa première connexion.

3. Les droits d accès sont attribués automatiquement selon le rôle attribué.
   Aucune configuration manuelle des droits n est nécessaire.

4. Le Patron ou Co-Patron peut à tout moment : modifier le rôle d un compte,
   le suspendre (licenciement) ou le supprimer définitivement.

## FORMAT DES LOGS DISCORD À PARSER (via Bot Discord)

### 1. logs-ig (Inventaire)
```
Type: inventory-add OU inventory-remove
Champs: discord, name, properName, characterId, source, count, item, metadata, owner
```
→ Stock en temps réel + comptage bidons/caoutchoucs pompistes

### 2. logs-services (Heures de travail)
```
"Service commencé/terminé" + Prénom NOM + timestamp
```
→ Suivi RH (informatif, non bloquant pour la paie)

### 3. suivi-facture (Ventes)
```
Facture #ID — Payée
Émetteur: @Discord — Prénom NOM (vendeur)
Destinataire: @Discord — Prénom NOM (client)
Montant: X $
Raison: description produits vendus
Paiement: Espèces / Carte
```
→ CA hebdo + calcul commissions + corrélation logs-ig

### 4. suivi-achat-essence (Redistribution essence)
```
Redistribution N°XXXXX — [Nom Station]
Montant facturé / Prix du litre / Litres consommés
Stock avant / Stock après / Niveau %
```
→ Stock par station + comptage bidons pompistes

### 5. dépenses (Sorties d'argent)
```
SORTIE D'ARGENT
Compte ID / Utilisateur / Montant / Solde avant / Solde après / Raison
```
→ Charges comptables (déductibles ou non)

### 6. paie (Paiements employés)
```
PAIEMENT D'UN EMPLOYÉ
Payeur: Prénom NOM + ID Discord + ID Perso
Bénéficiaire: Prénom NOM + ID Discord + ID Perso
Montant: XXXX $
```
→ Masse salariale + vérification conformité TTE

### 7. suivi-coffre (Snapshot coffre)
```
PANEL COFFRE
Coffre: action-XXXXX-0-X / Items distincts / MAJ
Détail: nom_item → Quantité / Dernière maj / Par
```
→ Inventaire temps réel + alertes stock

Canaux supplémentaires à surveiller (stockage brut) :
suivi-coffre-secondaire, alerte-coffre, revenu, factures, statsbank,
logs-licenciement, logs-avertissement

## MODULE COMPTABILITÉ (conforme TTE Chapitre IV — Secteur 2)

Postes hebdomadaires (lundi 00h00 → dimanche 23h59) :
- CA : total ventes (suivi-facture)
- Autres entrées : saisie manuelle
- Charges déductibles : matières premières, frais avocat (max 30 000$), entretien véhicules
- Charges non déductibles : toutes les autres
- Salaires versés (paie)
- Primes hebdomadaires et mensuelles
- Résultat imposable = (CA + Autres entrées) - Charges déductibles
- Bénéfice net = Résultat imposable - Impôts

Règles TTE automatiques :
- Masse salariale max = 90% du CA
- Plafonds salaire : 19 000$/sem employés, 20 000$/sem direction/gestion
- Primes hebdo selon tranches CA (Art. 4-1.10)
- Primes mensuelles selon tranches bénéfice net (Art. 4-1.11)
- Clôture automatique dimanche 00h00
- Conservation données 6 semaines minimum

Export : rapport PDF/CSV par semaine avec tous les postes comptables.

## CALCUL DE LA PAIE (au prorata du travail réel)

### VENDEURS — Commission sur le BÉNÉFICE de vente
Bénéfice = prix de vente - prix d'achat du produit

Calcul au prorata du CA généré vs plafond CA :
Si vendeur génère 50% du CA plafond → 50% du salaire max.

| Grade          | Salaire max | Commission | CA plafond |
|----------------|-------------|------------|------------|
| Novice         | 13 000 $/sem| 32.5%      | 40 000 $   |
| Intermédiaire  | 14 000 $/sem| 35%        | 40 000 $   |
| Expérimenté    | 15 000 $/sem| 37.5%      | 40 000 $   |

Formule :
  Salaire = min(Bénéfice total × % commission, Salaire max)
  Si CA généré > 40 000$ → seuls les 40 000 premiers $ comptent
  Les 7h de service = indicateur RH uniquement, ne bloquent pas la paie

### RESPONSABLES (Vente & Pompiste)
Salaire fixe max : 17 000 $/sem
Pas de CA obligatoire — évaluation manuelle par le patron.

### POMPISTES — Quota bidons + caoutchoucs (au prorata)

Quota hebdomadaire (modifiable depuis l'interface admin) :
  - Bidons d'essence à ravitailler : 1 700 bidons/sem
  - Caoutchoucs à produire : 800 unités/sem

Calcul :
  Score bidons     = bidons réalisés / 1 700 (max 100%)
  Score caoutchouc = caoutchoucs réalisés / 800 (max 100%)
  Score global     = (Score bidons + Score caoutchouc) / 2
  Salaire          = Score global × Salaire max du grade

| Grade          | Salaire max |
|----------------|-------------|
| Novice         | 13 000 $/sem|
| Intermédiaire  | 14 000 $/sem|
| Expérimenté    | 15 000 $/sem|

Source : logs-ig (inventory-add sur items bidons et caoutchoucs)

### DIRECTION (fixe, hors primes — plafond TTE Secteur 2)

| Poste      | Salaire fixe max/sem |
|------------|----------------------|
| Patron     | 20 000 $             |
| Co-Patron  | 20 000 $             |
| DRH        | 20 000 $             |
