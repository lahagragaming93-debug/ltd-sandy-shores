# 4 — Création du premier compte (Patron)

> Durée : 2 minutes

## Procédure

1. Ouvrir l'URL GitHub Pages : `https://<pseudo>.github.io/ltd-sandy-shores/`
2. Cliquer sur l'onglet **Inscription Direction** (à droite)
3. Remplir :
   - **Rôle** : `Patron`
   - **Prénom RP** + **NOM RP**
   - **Email** (peut être un email personnel — sert juste pour la connexion)
   - **Mot de passe** (≥ 8 caractères)
4. **Créer mon compte**

→ Redirection automatique vers le **Tableau de bord**.

## Compte Co-Patron (étape suivante)

Le Co-Patron suit la même procédure (onglet Inscription, choisit `Co-Patron`).

> ⚠️ Une fois ces deux comptes créés, l'inscription publique est verrouillée.
> Tous les autres comptes (DRH, responsables, employés) sont créés depuis
> **Administration**.

## Initialiser le catalogue produits

1. Aller dans **Stocks épicerie**
2. Cliquer sur **Réinitialiser depuis catalogue**
3. Confirmer

→ 53 produits sont créés avec les prix de vente définis dans le projet.
   Les prix d'achat sont à 0 — à saisir manuellement (cliquer **Modifier**
   sur chaque ligne et renseigner le prix d'achat).

## Configurer les stations essence

1. Aller dans **Stations essence**
2. Cliquer sur **+ Ajouter une station**
3. Saisir nom, capacité, seuil d'alerte, prix au litre
4. Recommencer pour les 8 stations

## Créer les autres comptes

1. **Administration** → **+ Créer un compte**
2. Pour chaque employé : prénom, NOM, email, ID Discord, ID Perso, rôle
3. Le mot de passe provisoire est généré automatiquement
4. **Transmettre les identifiants** affichés (email + mot de passe) à l'employé
5. À sa première connexion, l'employé sera invité à choisir son mot de passe
